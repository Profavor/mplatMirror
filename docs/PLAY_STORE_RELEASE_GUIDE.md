## 2. 배포용 번들(AAB) 빌드

Google Play는 APK 대신 **AAB (Android App Bundle)** 포맷만 허용합니다.

### 2.1 빌드 실행
터미널에서 아래 명령어를 실행합니다:

```bash
cd /home/profavor/mMirror/android
./gradlew bundleRelease
```

### 2.2 생성된 AAB 파일 위치
빌드가 완료되면 다음 경로에 최종 업로드용 번들이 생성됩니다:
```text
android/app/build/outputs/bundle/release/app-release.aab
```

*서명 설정(`signingConfigs.release`)은 `android/app/build.gradle.kts`에 이미 `upload-keystore.jks`로 자동 서명되도록 구성되어 있습니다.*

## 3. 가장 중요한 심사 통과 핵심 포인트 (★필독★)

mplat Mirror는 **화면 캡처**와 **원격 터치(접근성)** 기능을 사용하므로, 구글의 정책 설문에서 **정확한 사유**를 입력해야 한 번에 승인됩니다.

### 3.1 접근성 서비스(Accessibility Service) 심사 대응
> ⚠️ **구글이 가장 엄격하게 보는 항목입니다.**

1. **사용 목적 (Play Console 설문 작성 예시):**
   > "차량(테슬라) 대화면 웹 브라우저에서 운전자가 화면을 터치/클릭할 때, 핫스팟 로컬 네트워크를 통해 제스처 좌표를 수신하여 스마트폰 화면에 1:1로 입력하기 위한 원격 조작 보조 기능으로 사용됩니다. 어떠한 개인정보나 화면 텍스트도 외부로 수집하거나 저장하지 않습니다."
2. **필수 준비: 시연 동영상 (YouTube)**
   - 영상 길이: 1분 내외
   - 내용: 
     1. 스마트폰 앱에서 사용자가 직접 접근성 서비스를 켜는 화면 (Prominent Disclosure 노출 확인)
     2. 테슬라(또는 PC 브라우저) 화면에서 버튼을 클릭했을 때 스마트폰에서 실제로 터치가 반응하는 모습
   - 해당 유튜브 링크를 콘솔 설문의 `동영상 URL` 항목에 입력해야 거절당하지 않습니다.

### 3.2 화면 캡처/미디어 프로젝션(Foreground Service) 대응
- **선언된 서비스 유형:** `mediaProjection`, `connectedDevice`
- **목적 기술 예시:**
  > "스마트폰의 화면을 H.264로 실시간 인코딩하여 테슬라 차량 웹 브라우저로 60FPS 초저지연 미러링 스트리밍을 제공하기 위해 사용자가 명시적으로 시작한 세션 동안에만 포그라운드 서비스를 실행합니다."

### 3.3 패키지 조회(`<queries>`) 선언 사유
- Android 11+ `<queries>` 태그 사용 사유:
  > "테슬라 화면의 앱 런처 바에서 스마트폰에 설치된 앱(내비게이션, 미디어 등) 목록을 표시하고, 사용자가 테슬라 화면에서 터치 시 해당 앱을 스마트폰에서 직접 실행(Launch)하기 위한 기능입니다."

## 4. Google Play Console 단계별 등록 절차

### Step 1: 앱 생성 & 기본 정보
1. [Google Play Console](https://play.google.com/console) 접속
2. **[앱 만들기]** 클릭
   - **앱 이름:** `mplat Mirror - 테슬라 미러링`
   - **기본 언어:** 한국어 (ko-KR)
   - **앱 또는 게임:** 앱
   - **무료 또는 유료:** 무료
   - **선언 체크:** 개발자 프로그램 정책 및 미국 수출법 동의 후 생성

### Step 2: 스토어 등록정보 작성
- **간단한 설명 (80자 이내):**
  > LTE/5G 데이터 소모 0MB! 스마트폰 핫스팟 로컬 초저지연 테슬라 무선 미러링 & 양방향 터치
- **자세한 설명 (4000자 이내):**
  > [mplat Mirror - 테슬라 0MB 초저지연 무선 미러링 & 양방향 터치]
  >
  > 스마트폰의 비싼 모바일 데이터를 단 1MB도 쓰지 않고, 순수 로컬 Wi-Fi 핫스팟으로 테슬라 대화면에 내 폰을 그대로 미러링하세요!
  >
  > 🌟 주요 기능:
  > 1. 모바일 데이터 소모 0MB (Zero-Data In-Car Mirroring)
  >    - 스마트폰 핫스팟 로컬 대역(UDP)을 직접 활용하여 LTE/5G 요금 폭탄 걱정 제로!
  > 2. 60 FPS 초저지연 (<50ms) 하드웨어 가속
  >    - 부드러운 60 프레임 전송으로 딜레이 없는 화면을 제공합니다.
  > 3. 양방향 정밀 터치 & 스크롤 지원
  >    - 테슬라 대화면에서 스마트폰을 직접 터치하고 조작하세요.
  > 4. 폴더블폰(Z 폴드/플립) 화면비 완벽 지원
  >    - 펼치거나 접어도 끊김 없이 해상도가 자동 전환됩니다.
  > 5. 순수 로컬 P2P 직결
  >    - 복잡한 VPN 없이 테슬라 브라우저(https://mplat-mirror.web.app)에서 바로 연결됩니다.
- **그래픽 에셋 등록:**
  - 앱 아이콘 (512x512)
  - 그래픽 이미지 (1024x500)
  - 휴대전화 스크린샷 4~8장 업로드

### Step 3: 앱 콘텐츠 및 정책 설문 작성 (중요)
좌측 메뉴 **[앱 콘텐츠]**에서 모든 항목을 '완료'해야 합니다:
1. **개인정보처리방침:** `https://mplat-mirror.web.app/privacy.html`
2. **광고:** '앱에 광고가 포함되어 있지 않음' 체크
3. **앱 액세스 권한:** '모든 기능 제한 없이 사용 가능' (또는 테스트용 가이드 기재)
4. **콘텐츠 등급:** 설문 진행 (설문 완료 시 만 3세 이상 전체이용가 획득)
5. **타겟층:** 만 18세 이상 (운전자 대상)
6. **데이터 보안 (Data Safety):**
   - 사용자 데이터를 외부 서버로 수집/공유하는가? -> **"아니요"** (100% 로컬 스트리밍)
7. **포그라운드 서비스 및 접근성 권한:** 3번 항목의 가이드 문구 기재

### Step 4: AAB 업로드 및 출시 트랙 선택
1. 좌측 메뉴 **[출시]** -> **[프로덕션]** (또는 내부 테스트)
2. **[새 버전 만들기]** 클릭
3. `android/app/build/outputs/bundle/release/app-release.aab` 파일 드래그 앤 드롭 업로드
4. **버전 이름:** `1.2.1` (또는 해당 배포 버전)
5. **출시 노트:**
   ```text
   - 테슬라 0MB 초저지연 로컬 P2P 미러링 지원
   - 양방향 정밀 터치 제스처 제어 안정화
   - 폴더블폰 화면 전환 대응 및 오디오 싱크 개선
   ```
6. **[버전 검토 및 저장]** -> **[심사 제출]**
